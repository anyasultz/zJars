## UwU Dimension source project

The Minecraft 1.21.1 NeoForge source is in this repository root. See [the build guide](docs/BUILD.md) for how Gradle downloads the Minecraft and NeoForge libraries automatically; those generated binaries are not stored in Git. Read [UwU-Dimension-README.md](UwU-Dimension-README.md) for the existing project guide and its established modpack dependencies. The Cupid Bow player-minion feature is implemented inside UwU Dimension and adds no external mod dependency of its own. The hosted 1.4.7 build is included at [artifacts/UwU-Dimension-1.21.1-1.4.7.jar](artifacts/UwU-Dimension-1.21.1-1.4.7.jar); the code handoff is in [docs/HANDOFF-Cupid-Player-Minions-1.4.7.txt](docs/HANDOFF-Cupid-Player-Minions-1.4.7.txt).
