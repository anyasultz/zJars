Standalone requirement
Keep the Cupid charm and minion feature implemented inside UwU Dimension using Minecraft and NeoForge. Do not add a dependency on Simply Swords, Ice and Fire, RLCraft, or another mod for the Cupid feature. The existing mod has established pack dependencies described in UwU-Dimension-README.md; preserve those unless separately asked to change them. The user's CurseForge profile and other mod JARs are not required for this code work. Simply Swords and Ice and Fire were mentioned only as optional design references; Ice and Fire's Siren pull behavior does not meet the requested minion behavior.

Requested behavior
The Cupid Bow charms eligible entities, including other players, for 40 seconds. Charmed allies should follow their owner, help fight, and obey a left-click target command while the owner holds the bow. Show the familiar Minecraft animal-love effect in pastel pink. The bow description should say it befriends eligible targets.

Implemented in this code copy
- Cupid Bow hits can charm players for 40 seconds, subject to PvP permission rules. The shooter, creative players, and spectators are excluded.
- Charmed players receive client-control packets to follow their owner or pursue a marked target; the server handles their attacks. Charmed mobs also receive the target command.
- Left-clicking with the Cupid Bow selects the nearest eligible living entity along the owner's unobstructed sightline and sends that owner's charmed allies after it. There is no fixed command-distance cap; selection scans entities loaded in the same dimension.
- Charm release is handled on expiry, death, logout, and dimension change.
- Pastel heart particles were enlarged and set to ignore the reduced-particle limiter. The tooltip and version were updated.
- The hosted GitHub Actions workflow packages the JAR.
