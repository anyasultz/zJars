Build setup
The project already has the NeoForge ModDev Gradle plugin and version configuration in build.gradle. Gradle downloads the matching Minecraft and NeoForge compile artifacts when it builds; they should not be checked into the repo. The wrapper must be executable for GitHub/Linux builds. See docs/BUILD.md. The basic jar build does not need a local libs/ folder; optional modpack JARs are fetched by ci/get-mods.sh for the fuller development client and expedition workflows.

Standalone requirement
Keep the Cupid charm and minion feature implemented inside UwU Dimension using Minecraft and NeoForge. Do not add an external mod dependency for Cupid charm behavior. The full mod retains its established runtime dependencies documented in UwU-Dimension-README.md and the mod metadata. Simply Swords and Ice and Fire were named as optional references; Ice and Fire's Siren pull behavior does not replace the requested minion behavior.

Requested behavior
The Cupid Bow charms eligible entities, including other players, for 40 seconds. Charmed allies follow their owner, help fight, and obey a left-click target command while the owner holds the bow. Use the familiar Minecraft animal-love effect recolored pastel pink. The bow description should say it befriends eligible targets.

Implemented
- Cupid Bow hits can charm players for 40 seconds, subject to PvP permission rules. The shooter, creative players, and spectators are excluded.
- Charmed players receive client-control packets to follow their owner or pursue a marked target; the server handles their attacks. Charmed mobs receive the same target command.
- Left-clicking with the Cupid Bow selects the nearest eligible living entity along the owner's unobstructed sightline and sends that owner's charmed allies after it. There is no fixed command-distance cap; selection scans entities loaded in the same dimension.
- Charm release is handled on expiry, death, logout, and dimension change.
- Pastel heart particles were enlarged and set to ignore the reduced-particle limiter. Tooltip and mod metadata identify version 1.4.7.
